# Proyek Aplikasi Hydro & Discharge Surveyor Mobile

Aplikasi lapangan untuk:
1. Penaksiran potensi daya mikro-minihidro (Head + Debit + Rekomendasi Turbin).
2. Pengukuran hidrologi debit aliran sungai saja (tanpa unsur terjunan).

## Fitur Utama
- Watermarking GPS & Timestamp otomatis pada foto.
- Generator Berita Acara (BASL) PDF 1 lembar A4 dengan tanda tangan digital ketua tim.
- Mode Offline-first dengan antrean SQLite lokal.
- Build otomatis APK gratis via GitHub Actions.
